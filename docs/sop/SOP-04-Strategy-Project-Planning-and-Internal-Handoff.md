# THE EXALTED MEDIA
# SOP 04 — Strategy, Project Planning & Internal Handoff

## Primary Owner
Project Manager / Client Success Manager

## Strategic Owner
Agency Owner / Strategist

## Purpose
Turn client requirements into a clear delivery plan.

## Main Process
1. Review sales handoff.
2. Review onboarding information.
3. Confirm business goal.
4. Confirm target audience.
5. Confirm offer.
6. Define customer journey.
7. Define project scope.
8. Define exclusions.
9. Define deliverables.
10. Define milestones.
11. Define timeline.
12. Assign team members.
13. Identify dependencies.
14. Identify risks.
15. Define success metrics.
16. Create project brief.

## Completion
Approved project plan exists and production work can begin.
